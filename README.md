Consumption Tracker - User Manual


Setup:
Enter your interval (days between consumption)
Click "Start Tracking"

Calendar Colors:
Green = Allowed to consume
Red = Too soon (blocked by interval)

Marking Days:
Tap a day to mark consumption
Grey X = Consumed when allowed
Red X = Consumed when blocked
Tap again to remove

Interval Button:
Green = Today is allowed
Red = Today is blocked or already consumed
Shows days remaining until next allowed day

Change Interval:
Tap the interval button
Enter new number
Click "Change"

Tips:
Swipe left/right to change months
Data saves automatically to your device
Works offline once installed

Installing as App:
Android/Chrome: Menu → "Add to Home screen"
iOS/Safari: Share → "Add to Home Screen"
